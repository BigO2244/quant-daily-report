has moved to `docs/governance/fr_registry.md`.

## Canonical History

Use `docs/governance/fr_registry.md` for:

- deployed FRs
- deployed-observing FRs
- reviewed deferred FRs
- wave summaries
- validation summaries
- rollback references
- final or current operational state

Use `docs/governance/fr_governance_model.md` for status semantics, observation
windows, blast-radius classification, validation philosophy, and rollback
discipline.

Use `docs/governance/operational_lessons.md` for deployment learnings,
operational anti-patterns, degraded-state lessons, and future governance
guidance.

## Historical Boundary

The registry preserves the Waves 1-3 deployment history, FR-008 deployment
governance recovery, reviewed deferred items, and Phase 4 foundation status.
Do not add new execution-history rows here; add them to the registry instead.
