# Completed Legacy Model Intakes

This directory contains readable intake packets for model research completed
before Alpha Lab or outside its governed experiment workflow.

Create each packet from `../templates/LEGACY_MODEL_INTAKE.md` and name it:

```text
LEGACY-YYYY-NNN_short_slug.md
```

Rules:

- Hash and reference the original files; do not rewrite or silently normalize
  the source result.
- Preserve original research dates, authorship, parameters, variants, and
  reported outcomes.
- State point-in-time, survivorship, cost, multiple-testing, holdout, and
  reproducibility limitations explicitly.
- Do not call legacy work preregistered or decision-grade retroactively.
- Add every completed legacy ID and reusable lesson to
  `../MODEL_COMPENDIUM.md` in the same reviewed change.
- A draft or pending intake cannot satisfy the prior-model review gate for a
  new hypothesis.

The short moving-average analysis is pending intake. No completed legacy packet
exists until the original files are identified and hashed.
